# Night Watch: Aswang Hunt

A cooperative survival horror game inspired by Filipino folklore and rural Philippine life in the 1990s. Players take the roles of ordinary barangay residents who learn about mysterious deaths in nearby communities believed to be caused by aswangs. After receiving the news in the morning, the residents prepare supplies and weapons during the day. When night falls, they must work together to hunt the creatures and protect their community.

## Install

1. Clone the repository.
2. Open the project in Roblox Studio.
3. Place the scripts in the appropriate locations as specified below.
4. Run the game in Roblox Studio to test and play.

## Use

1. Place `main.lua` in the `ServerScriptService`.
2. Place `player.lua` in the `StarterPlayerScripts`.
3. Place `enemy.lua` in the `ServerScriptService`.
4. Place `map.lua` in the `ServerScriptService`.
5. Place `ui.lua` in the `StarterPlayerScripts`.
